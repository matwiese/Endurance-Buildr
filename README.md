# Endurance-Buildr

## Kaderauswertung Segeln mit VALD-Sprungdaten

**`kaderauswertung_segeln_vald.html`** – Segeln-Kaderauswertung (Einzel- und Teamauswertung) mit der Rohdaten-Auswertung des CMJ Analyzers: Erkennung von CMJ, SJ und Single Leg links/rechts, Parameter-Panel mit gespeicherten Kombinationen, VALD-Import und ein dauerhafter Sprungspeicher, aus dem die Auswertungen rechnen.

→ Anleitung, Funktionsweise und Entwicklung: [docs/KADERAUSWERTUNG_VALD.md](docs/KADERAUSWERTUNG_VALD.md)

Weitere Dateien im Repository: `CMJ_Analyzer_offline (33).html` (CMJ Analyzer), `Sprint_FVP_Team_Auswertung (5).html`, `kaderauswertung_segeln (3).html` (Ausgangsstand der Segeln-Auswertung), Endurance Map Tool (`download`, `app.js`, `styles.css`).
